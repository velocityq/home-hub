Connect to your home hub

On the Mac that runs the hub, open Terminal in the home-hub folder and run this. It shows the address to type here and a 6 digit code.

cd hub && .venv/bin/python -m hubserver pair

  1. The tablet and the Mac must be on the same Wi-Fi.
  2. The code works once, for 10 minutes. Run the command again for a new one.
  3. The tablet only ever talks to the hub, on your home network.
